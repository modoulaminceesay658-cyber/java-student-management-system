# Student Management System

## Project Overview
A simple console-based Student Management System developed using Java as an academic programming project.

## Features
Add student records
View all student records
Search for students by matric number
Update student information
Delete student records
Validate basic user input

## Technologies
Java
Object-Oriented Programming
ArrayList
Scanner
IntelliJ IDEA

## How to Run
Install a compatible Java Development Kit (JDK).
Open the project in IntelliJ IDEA.
Open StudentManagementSystem.java.
Run the main method.
Follow the instructions displayed in the console.

## Limitations
Student records are stored in memory and are lost when the program closes. Database and permanent file storage are not implemented.
